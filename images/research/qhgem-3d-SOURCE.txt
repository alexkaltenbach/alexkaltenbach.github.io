The plots use the original rho0 and rhoT arrays (91 x 91), at t=0 and
t=T=0.3, without transposition (row y, column x). Both views use identical
orthographic cameras, density heights, and spatial extent [-12,12]^2.
This central view lies inside the original domain (approximately
[-15.824,15.824]^2). All displayed grid values are retained; the surfaces
connect the actual saved samples. No fitted values, new time integration,
data smoothing, or independent normalization has been introduced.

The colormap is the original Figure 5 Parula table, imported without
modification from _parula.py in the reference repository. Its linear
normalization [0,0.13868966591054607] is also the original Figure 5 range.
The two height axes both span [0,0.115], enclosing all displayed heights.
The former blue-only palette and nonlinear gamma transform were removed.
Typography uses STIXGeneral with STIX mathematical labels. PNG, SVG and PDF
exports are generated from the same script.

The colormap module itself is CC BY-SA 4.0 (PetSven,
https://stackoverflow.com/a/60007513; attribution retained in _parula.py).
This license concerns the copied colormap module; the simulation data and
other original QH-GEM code carry their BSD 3-Clause license.

The final density is a computed approximation, not a certified local
minimum or an optimization-convergence result. The target is not plotted.
The full-grid L2 difference from the target is 0.02164511618150967,
matching the archived value. Initial and final mass are
1.0000000000000036 and 0.999999999999949; see validation.json.
