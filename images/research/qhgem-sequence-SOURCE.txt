The first four panels use all four original rho_snapshots arrays (91 x 91),
at t=0, T/3, 2T/3, T, where T=0.3. The separately labelled fifth panel uses
the archived rho_target array. This matches the temporal selection and
comparison in Figure 5 of the preprint, with surfaces instead of heatmaps.
No time interpolation, fitted values, smoothing, new integration or
independent normalization has been introduced. Row y / column x orientation
is preserved. The saved t=0 snapshot includes the original solver's density
floor; its maximum difference from rho0 is less than 4e-22.

All panels use identical orthographic cameras and spatial extent [-12,12]^2,
inside the original domain (approximately [-15.824,15.824]^2). All displayed
grid values are retained. The shared height axis [0,0.15] contains the higher
intermediate peaks as well as the initial, terminal and target densities.
The original Figure 5 Parula table is used without modification, with the
original common linear color normalization [0,0.13868966591054607].
Typography: DejaVu Sans, including mathematical labels.
Desktop: all five panels in one row. Mobile: four snapshots in a 2x2 grid,
followed by the separate target. Dashed separators identify the target as
a comparison, not an additional time step.

https://stackoverflow.com/a/60007513; attribution retained in _parula.py).
This license concerns the copied colormap module; the simulation data and

The final density is a computed approximation, not a certified local
minimum or an optimization-convergence result. The full-grid L2 difference
from the target is 0.02164511618150967, matching the archived value.
Each archived time snapshot has unit mass to better than 1e-12.
All validation results are recorded in validation.json.
